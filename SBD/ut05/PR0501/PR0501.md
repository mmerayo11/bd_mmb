```
from vega_datasets import data  
import pandas as pd
import altair as alt
df = data.cars()
```


## 1. Relación potencia-eficiencia por región:

```
( alt.Chart(df)
     .mark_point()
     .encode(
        alt.X('Horsepower:Q'),
        alt.Y('Miles_per_Gallon:Q'),
        alt.Color('Origin')
    )
)
```

## 2. Análisis de peso y cilindrada

```
( alt.Chart(df)
     .mark_point()
     .encode(
        alt.X('Weight_in_lbs:Q'),
        alt.Y('Acceleration:Q'),
        alt.Size('Cylinders:O'),
        alt.Color('Origin')
    )
)
```

## 3. Comparativa de consumo por origen

```
( alt.Chart(df)
     .mark_bar()
     .encode(
        alt.X('Origin'),
        alt.Y('average(Miles_per_Gallon):Q'),
    )
)
```

## 4. Distribución de modelos en el tiempo

```
( alt.Chart(df)
     .mark_point()
     .encode(
        alt.X('Year:T'),
        alt.Y('Origin'),
        alt.Size('count()'),
    )
)
```

## 5. Análisis de evolución temporal y variabilidad

```
( alt.Chart(df)
     .mark_line()
     .encode(
        alt.X('Year:T'),
        alt.Y('mean(Horsepower):Q'),
        alt.Color('Origin')
    )
)
```

```
( alt.Chart(df)
     .mark_area(opacity=0.3)
     .encode(
        alt.X('Year:T'),
        alt.Y('min(Horsepower):Q'),
        alt.Y2('max(Horsepower):Q'),
        alt.Color('Origin')
    )
)
```

## 6. Experimentación de marcas

```
( alt.Chart(df)
```
